Catatan Belajar GitHub

Dokumentasi perjalanan belajar, percobaan, dan pengalaman.

Sabtu, 21 November 2026

Hari ketika proses commit dan push mengalami kegagalan

Hari ini, saya bersama tim IT dan pembina ekstrakurikuler, yaitu Pak Zul, mengalami kegagalan saat mencoba melakukan commit dan push dari Visual Studio Code (VS Code) ke GitHub.

Kegagalan tersebut terjadi karena beberapa kendala yang kami temui selama proses pembelajaran dan praktik. Berikut adalah beberapa hal yang menjadi penyebabnya:

  1. Permasalahan pada komputer laboratorium TKJ. Setiap kali pengguna atau siswa menginstal aplikasi desktop, seperti Adobe Premiere dan aplikasi lainnya, proses instalasi berjalan dengan baik dan aplikasi bahkan dapat digunakan. Namun, setelah komputer direstart, aplikasi yang sebelumnya diinstal justru menghilang. Hal ini membuat proses instalasi harus dilakukan kembali.
  2. Kendala saat pendaftaran akun GitHub. Banyak kegagalan juga terjadi pada tahap awal, yaitu ketika mencoba mendaftarkan akun GitHub. Hal ini diduga karena terlalu sering melakukan percobaan pendaftaran menggunakan alamat IP yang sama dalam waktu yang sangat singkat, bahkan kurang dari tiga detik. Akibatnya, proses pendaftaran tidak berjalan sebagaimana mestinya.

Catatan: Pengalaman ini menjadi bagian dari proses belajar saya dalam memahami Git, GitHub, serta penggunaan lingkungan pengembangan di laboratorium.
